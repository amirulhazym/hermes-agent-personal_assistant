# Phase 1: Reference Extraction Checklist

Extract PRINCIPLES, not elements. For each reference, answer:

## Structural Principles

- [ ] What layout structure does the reference use? (single column, sidebar, split, grid, asymmetric)
- [ ] What makes the hierarchy work? (size contrast, color contrast, spacing, position)
- [ ] How does it handle density? (tight vs airy, where is breathing room, where is density justified)
- [ ] What's the rhythm? (repeating patterns, section pacing, content-to-whitespace ratio)
- [ ] How does it handle the hero/top area? (full-bleed, contained, minimal, rich)

## Visual Principles

- [ ] What's the color posture? (monochrome + single accent, full palette, tonal)
- [ ] How many colors does it actually use? (count them — most great designs use 3-5 max)
- [ ] What's the typography stance? (single family, contrast pair, editorial, technical)
- [ ] How does it use surfaces? (cards, flat, elevated, bordered, shadow-driven)
- [ ] What's the mood? (warm, cold, energetic, calm, premium, utilitarian)

## Interaction Principles

- [ ] What happens on hover? (scale, color shift, underline, nothing)
- [ ] What's the navigation style? (top bar, sidebar, full-screen menu, inline)
- [ ] How does scrolling feel? (smooth sections, parallax, sticky elements, simple)
- [ ] What feedback exists for user actions? (toast, animation, state change, none)

## Constraints Discovered

- [ ] What did the reference deliberately NOT do? (no carousel, no sidebar, no gradients)
- [ ] What would break the design? (too many colors, too much text, too many CTAs)
- [ ] What accessibility choices are visible? (contrast, font size, focus indicators)

## Documentation

Write findings as principles, not element descriptions.

**Good:**
> "The reference uses one bold accent on a neutral canvas — every colorful element earns its place."
> "Spacing is governed by an 8px grid with deliberate exceptions at section boundaries for rhythm."

**Bad:**
> "They use purple for the button."
> "The header is 64px high."

Store these principles — they'll guide the Render phase and survive the Rebuild.
