# UI/UX Pro Max — Design Intelligence Engine

> AI design system generator with 67 styles, 161 palettes, 57 fonts. Use FIRST for every new project.

## Usage

This skill generates complete design systems based on project requirements.

## Workflow

### Step 1: Project Analysis
- What is the project? (landing page, app, dashboard, etc.)
- Who is the target audience?
- What mood/feeling should it convey?
- What are the brand values?

### Step 2: Style Selection
Choose from 67 styles: Minimalist, Brutalist, Glassmorphism, Neumorphism, Dark Mode, Light Mode, Cyberpunk, Retro, Corporate, Playful, Luxury, Tech, and many more.

### Step 3: Color Palette Generation
Generate from 161 palettes: Primary, Secondary, Accent, Background, Surface, Error, Text (primary, secondary, disabled), Semantic (success, warning, info).

### Step 4: Typography System
Select from 57 fonts: Heading font (display), Body font (readable), Mono font (code). Size scale: xs, sm, md, lg, xl, 2xl, 3xl.

### Step 5: Component Specifications
Define: Buttons (primary, secondary, ghost, danger), Cards (elevated, outlined, filled), Forms (inputs, selects, checkboxes), Navigation (header, sidebar, tabs), Modals, Toasts, Tooltips.

### Step 6: Spacing and Layout
Base unit (4px, 8px), Spacing scale (1x, 2x, 3x, 4x, 6x, 8x), Grid system (columns, gutters, margins), Breakpoints (mobile, tablet, desktop).
