# Taste Skill — Anti-Slop Design Rules

> Quality gate for all design work. Run pre-flight checklist before EVERY delivery.

## Core Principles

1. **Less is more** — Remove anything that doesn't serve a purpose
2. **Consistency** — Use established patterns, don't reinvent
3. **Hierarchy** — Guide the eye with size, weight, color
4. **Whitespace** — Let content breathe
5. **Restraint** — One accent color, one font family, one star element

## Anti-Slop Checklist

### Layout
- [ ] Visual hierarchy clear (H1 → H2 → H3 → body)
- [ ] Whitespace balanced (not cramped, not empty)
- [ ] Grid system consistent (8px or 4px base)
- [ ] Responsive at 375px, 768px, 1440px

### Color
- [ ] Max 3-4 colors in palette
- [ ] Contrast ratio ≥ 4.5:1 for text
- [ ] No rainbow gradients
- [ ] Dark/light mode considered

### Typography
- [ ] Max 2 font families
- [ ] Size scale consistent (1.25x or 1.333x ratio)
- [ ] Line height 1.5-1.7 for body text
- [ ] No ALL CAPS except for short labels

### Motion
- [ ] Animations purposeful (not gratuitous)
- [ ] Duration 200-500ms for transitions
- [ ] Easing: ease-out for entrances, ease-in for exits
- [ ] No infinite animations (except loaders)

### Elements to AVOID
- ❌ Rainbow gradients
- ❌ Comic Sans / Papyrus
- ❌ Drop shadows on everything
- ❌ Marquee text
- ❌ Auto-playing video with sound
- ❌ Pop-ups on load
- ❌ Cookie banners that block content

## Quality Score

Rate each design 1-10 on:
- Visual Appeal
- Clarity
- Consistency
- Originality
- Polish

Minimum passing score: 7/10 average
