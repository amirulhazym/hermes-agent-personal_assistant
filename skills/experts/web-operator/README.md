# Web Operator (PX-1b)

Phone-first interactive web operator skill pack.

## Install (VPS, only after explicit approval)

```bash
mkdir -p ~/.hermes/skills/experts
cp -a skills/experts/web-operator ~/.hermes/skills/experts/
mkdir -p ~/.hermes/scripts/web_operator
cp -a scripts/web_operator ~/.hermes/scripts/
mkdir -p ~/.hermes/web-operator/{state,profiles,quarantine,artifacts,keys}
```
